# Security

## Reporting a security problem

Please report security problems privately, not in a public issue or discussion.

Our preferred way is through GitHub: open the [Security tab](https://github.com/celerp/celerp/security) of this repository and choose **Report a vulnerability**. Your report stays private between you and the maintainers until a fix is released.

If you can't use GitHub, email security@celerp.com.

Please include the Celerp version, the steps to reproduce the problem, and what someone could do with it.

## What happens next

We aim to reply within a few business days and will keep you updated while we work on a fix. When the fix is released we publish a security advisory and credit you by name or GitHub handle, unless you would rather stay anonymous.

## Supported versions

Security fixes go into the latest release. Please update to the newest version before reporting.

## Thanks

We thank everyone who has reported a security problem responsibly.
